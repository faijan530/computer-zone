# Computer Zone Laptop Static Website

VS Code-ready static landing page extracted from the supplied `Pasted text.txt`.

## Run

Open this folder in VS Code and open `index.html` with Live Server, or open `index.html` directly in a browser.

## Stack

- HTML
- CSS
- Vanilla JavaScript
- No backend
- No database
- No build step
- No npm dependency

## Source separation

- `index.html` — page markup
- `css/style.css` — all original CSS
- `js/script.js` — all original JavaScript interactions/animations
- `assets/` — local asset folders

## Module organization in the supplied source

1. Brand / Hero
2. Laptop Discovery & Product Experience
3. Trust / CTA / Footer Experience
4. Performance & Technology
5. Remaining final-page experience as defined by the supplied source comments

The source's existing module comments are preserved in the extracted CSS/JS.
